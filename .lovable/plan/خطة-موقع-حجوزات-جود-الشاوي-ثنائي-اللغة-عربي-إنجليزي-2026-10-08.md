# خطة: موقع حجوزات جود الشاوي — ثنائي اللغة (عربي / إنجليزي)

## الهدف
بناء موقع حجوزات حقيقي وجاهز للاستخدام لفنانة المكياج جود الشاوي (القصيم — بريدة)، بقاعدة بيانات ونظام إدارة وربط فعلي بتقويم Google — مع دعم كامل للغتين العربية والإنجليزية وتبديل فوري بينهما.

## ١. التصميم والهوية
- هوية أنيقة: أبيض + أسود فحمي + عنابي عميق للأزرار والتفاصيل.
- خط عربي جميل (مثل IBM Plex Sans Arabic أو Tajawal) وخط لاتيني متناسق للإنجليزية.
- تصميم للجوال أولًا، يعمل بامتياز على اللابتوب والتابلت.
- الصفحة الرئيسية مختصرة: الاسم، تعريف قصير، نماذج الأعمال، الخدمات والأسعار، زر «اطلبي موعدكِ».
- صور أعمال جود تُرفع من لوحة الإدارة فقط — لا صور مولدة ولا تقييمات مختلقة.

## ٢. اللغة والاتجاه (الميزة الجديدة)
- زر تبديل لغة واضح في أعلى الموقع (عربي ⇄ English).
- العربية هي اللغة الافتراضية مع اتجاه RTL؛ الإنجليزية مع اتجاه LTR.
- التبديل فوري دون إعادة تحميل، ويُحفظ اختيار الزائرة.
- كل نصوص الموقع مترجمة: الصفحات العامة، رحلة الحجز كاملة، رسائل الحالات والسياسات، صفحة متابعة الطلب، ولوحة الإدارة.
- الأرقام والأسعار والتواريخ تُعرض بصيغة مناسبة لكل لغة، مع بقاء التوقيت Asia/Riyadh.

## ٣. الخدمات والأسعار (ثابتة)
- سهرة: 300 ريال/شخص — ملكة: 500 ريال/شخص — عروس: 700 ريال — الرموش مجانية.
- حجز متعدد الأشخاص مع حساب تلقائي للمجموع والعربون (50 ريال/شخص سهرة أو ملكة، 200 ريال/عروس).
- رسوم المشوار والإضافات بنود منفصلة؛ تُحددها جود عند المراجعة ولا تُعرض كمجانية.
- خدمة شعر اختيارية مع المصففة سارة (200–350 ريال، عروس 400) — تأكيد منفصل ولا تُطبق عليها سياسة عربون المكياج.

## ٤. رحلة الحجز (بدون إنشاء حساب)
الخدمات والعدد ← المكان (عند جود / داخل بريدة / خارج بريدة) ← التاريخ والوقت المتاح ← البيانات ← المراجعة والموافقة على السياسة ← الإرسال.
- منع زيارة منزلية لمكياج سهرة لشخص واحد مع توضيح لطيف.
- بعد الإرسال: رقم طلب + رابط متابعة خاص وآمن (رمز عشوائي غير قابل للتخمين).
- سياسة الإلغاء معروضة: «العربون غير مسترد عند الإلغاء من طرف العميلة».

## ٥. حالات الطلب والعربون (24 ساعة)
قيد المراجعة ← موافقة مبدئية (بانتظار العربون) ← إيصال قيد التحقق ← مؤكد نهائيًا / مرفوض / منتهي المهلة / ملغي.
- عند الموافقة المبدئية: إعادة فحص التوفر، حجز مؤقت، مهلة 24 ساعة بساعة الخادم، عرض بيانات التحويل البنكي (تدخلها جود من الإعدادات).
- رفع إيصال التحويل ينقل الطلب إلى «قيد التحقق» ويوقف الإلغاء التلقائي.
- مهمة مجدولة على الخادم تلغي الحجوزات المنتهية المهلة حتى لو كان الموقع مغلقًا.
- الدفع تحويل بنكي فقط — لا بوابة دفع إلكترونية.

## ٦. ربط Google Calendar
- تفويض OAuth آمن من لوحة الإدارة؛ العميلات لا يحتجن حساب Google.
- جود تختار تقويم الحجوزات والتقاويم المؤثرة على الإتاحة.
- الإتاحة تشمل: أوقات العمل، الإجازات، الأحداث المشغولة، الحجوزات المؤكدة والمؤقتة، مدد الخدمات، وقت التجهيز والفاصل والتنقل.
- عند الموافقة المبدئية يُضاف حدث «بانتظار العربون»، يُحدَّث عند الدفع، ويُزال عند الإلغاء — دون مس أحداث جود الشخصية.
- منع الحجز المزدوج داخل قاعدة البيانات + إعادة فحص التوفر قبل الاعتماد.
- عند تعطل الربط: إيقاف اعتماد المواعيد المتأثرة مع تنبيه واضح لجود.

## ٧. لوحة الإدارة (محمية بتسجيل دخول)
- عرض يومي/أسبوعي، مراجعة الطلبات وقبولها/رفضها، تحديد رسوم المشوار، مراجعة الإيصالات وتسجيل استلام العربون.
- تنبيه للمواعيد القريبة من انتهاء المهلة، إضافة حجوزات واتساب/اتصال والإجازات والفترات المحجوبة.
- إعدادات إلزامية قبل فتح الحجز: مدة كل خدمة، وقت التجهيز، الفاصل بين المواعيد، أوقات العمل، البيانات البنكية، سياسة المواعيد القريبة (<24 ساعة).
- إدارة صور الأعمال (رفع/ترتيب/حذف) وتعديل بيانات التواصل.
- سجل تغييرات حالة كل طلب.
- إشعارات: طلب جديد، موافقة مبدئية، تأكيد نهائي، إلغاء، تذكير قبل انتهاء المهلة. إلى حين ربط مزود رسائل: زر واتساب جاهز برسالة تتضمن رابط المتابعة + سجل إبلاغ يدوي.

## ٨. البيانات والأمان
- قاعدة بيانات حقيقية (Lovable Cloud) وعمليات خادم لحساب الأسعار والتحقق من التوفر وتغيير الحالات.
- حماية لوحة الإدارة بصلاحيات فعلية؛ إيصالات وبيانات العميلات خاصة؛ مفاتيح الربط على الخادم.
- حماية من تكرار الطلب والطلبات المزعجة.

## ٩. الاختبار والتسليم
- اختبار: طلبان متزامنان لنفس الوقت، حجز خارجي يحجب الفترة، حجز جماعي وعربونه ومدته، انتهاء المهلة دون فتح الموقع، رفع إيصال قبل المهلة، تعطل ربط التقويم، الجوال واللابتوب، والتبديل بين اللغتين في كل شاشة.
- تقرير نهائي: ما نُفذ واختُبر، ما بقي من بيانات/ربط خارجي، وتكاليف الخدمات الخارجية.

## تفاصيل تقنية
- Lovable Cloud (قاعدة بيانات + مصادقة + تخزين صور + دوال خادم).
- TanStack Start، Tailwind v4، نظام ترجمة (i18n) بملفي عربي/إنجليزي مع تبديل dir="rtl/ltr".
- Google Calendar API عبر OAuth (يتطلب موافقة جود على حسابها عند الربط).
- توقيت Asia/Riyadh في كل الحسابات والإشعارات.
- بيانات مطلوبة من جود قبل التفعيل الكامل: مدد الخدمات، أوقات العمل، البيانات البنكية، رسوم المشوار، ربط حساب Google، صور الأعمال.
