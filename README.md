# Jood Alshawi Studio

A bilingual makeup studio website based in Buraidah, Saudi Arabia. Designed to showcase the studio’s work and make appointment booking simple.

## Features

- Arabic and English with RTL and LTR layouts
- Makeup services and portfolio gallery
- Appointment booking and status tracking
- Booking management and studio settings
- WhatsApp and social media links

## Tech Stack

React · TypeScript · TanStack Start · Tailwind CSS · Supabase
